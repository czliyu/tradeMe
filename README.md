## 两本书的关系

- **第一本**建立完整体系：从心理到技术指标、交易系统、风险管理；
- **第二本**聚焦交易中最难的环节——**卖出**：止盈考验纪律、止损考验自尊、做空与熊市课程补全多头思维的盲区。
